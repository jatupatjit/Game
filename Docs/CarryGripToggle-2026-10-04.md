# ระบบจับลังแบบคลิกสลับ — 4 ตุลาคม 2026

## การควบคุม

- คลิกซ้าย: จับหรือปล่อยมือซ้าย
- คลิกขวา: จับหรือปล่อยมือขวา
- E: จับสองมือ หรือปล่อยทั้งสองมือ
- Q ค้างแล้วปล่อย: ชาร์จแล้วโยน
- ขยับกล้องขึ้นหรือลง: เปลี่ยนความสูงที่ต้องการยก

การคลิกสลับใช้กับสิ่งของที่ยกได้ ส่วนการปีนกำแพงใช้การกดค้างตามเดิม

## สิ่งที่แก้

- เก็บตำแหน่งและทิศฝ่ามือในพิกัดของลังตั้งแต่เริ่มจับ ไม่ย้ายจุดเดิมเมื่อเพื่อนหรืออีกมือเข้ามาจับ
- ยกเลิกการบังคับจุดจับด้านหลังให้เลื่อนมาด้านหน้า
- Host ยืนยันจุดจับ และส่ง cargo ID, สถานะมือ, contact, rotation กับ revision เป็น snapshot เดียว จึงใช้ได้กับผู้เล่นที่เข้ามาภายหลัง
- ส่งผลการจับกลับให้เจ้าของ พร้อมป้องกันผลเก่าทำให้กลับมาจับลังหลังจากปล่อยหรือโยน
- Input อยู่ใน Update; ตรวจผิว collider, ประมวลผลการจับ, collision pairs และฟิสิกส์อยู่ใน FixedUpdate
- IK มืออ่านตำแหน่งลังที่กำลังแสดงใน LateUpdate หลังจากการขยับตัวละคร
- เป้าหมายแรงยกอิงตำแหน่งไหล่ปกติที่ cache ไว้ และอ่าน Rigidbody pose แทนภาพที่ interpolate
- แรงหน่วงใช้ความเร็วสัมพัทธ์ระหว่างผู้ยกกับลัง แบ่งแรงตามจำนวนคนและมือ และชดเชยแรงโน้มถ่วงพอดี
- จำกัดการเดินให้อยู่ในระยะมือ และใช้ปริมาตร Collider กันลำตัวซ้อนลัง การชนฉากยังทำงานผ่าน CharacterController และ Rigidbody
- ปล่อยเมื่อ Stamina หมด, respawn, disconnect, ส่งของสำเร็จ หรืออยู่ไกลเกินระยะต่อเนื่อง
- UI แสดงวิธีคลิกจับและปล่อยแบบใหม่

## ขอบเขตระยะมือ

ตอนเริ่มจับของที่อยู่ไกล ระบบจะดึงของเข้าระยะก่อน แขนมีระยะยืดจำกัดที่ 1.25 เท่าของความยาวปกติสำหรับชดเชยการเคลื่อนไหวและเครือข่าย เมื่อของเข้าระยะ ข้อมือจะยึดกับ contact จริง หากติดสิ่งกีดขวางจนระยะเกินต่อเนื่องจะปล่อยของ

## แก้ตัวผู้เล่นซ้อนลังและ HP ลดตอนเริ่มยก

- คืนการชนระหว่างลังกับ CharacterController และ Collider ลำตัว ใช้นโยบายเดียวกันบน Host และ Owner; ignore เฉพาะ Collider เสริมของมือ/แขน
- เป้าหมายแรงยกอยู่พ้น radius + skin ของลำตัวจริง และอยู่ในระยะแขน เมื่อขอยกต่ำเกินไปจะปรับความสูงแทนการดึงจุดจับเข้าตัว
- ตรวจปริมาตรซ้อนด้วย ComputePenetration ใน FixedUpdate แทนระนาบผิวแบบไม่จำกัด จึงรองรับการจับด้านบนและลังที่เอียง
- ค่อย ๆ เปลี่ยนจาก contact เดิมไปเป้าหมายพยุงใน 0.35 วินาที และข้ามแรงผลักจากการเดินชนลังที่ตัวเองถือ
- จังหวะเริ่มยกคนแรกให้พื้นผิวที่สัมผัสอยู่ก่อนผ่อนแรงกระชาก 0.8 วินาที; คนช่วยเพิ่ม 0.2 วินาที การชนสิ่งกีดขวางใหม่ยังเสีย HP
- ความเสียหายกระแทกวัดความเร็วตั้งฉากกับผิว การเดินด้านข้างจึงไม่ถูกนับเป็นแรงกระแทกเต็มความเร็ว
- ความเสียหายลากต้องสัมผัสพื้นจริงใกล้ก้น Collider และลากต่อเนื่องอย่างน้อย 0.5 วินาที พร้อม cooldown เดิม ไม่ใช้ ray จากกลางลังที่ตรวจพื้นแม้ของลอยอยู่
- Collision callbacks เก็บ contact ลง buffer; คำนวณ HP ใน FixedUpdate และยังรับความเสียหายจาก hazard ภายนอกตามเดิม

Unity Editor recompilation ผ่านและ Console error = 0 ก่อนจบงาน; ยังไม่ได้เล่นยืนยันอาการแบบคนเดียวหรือหลายคนจริง ควรลองยกจากพื้น เดินเข้าลัง จับด้านบน ยกกับเพื่อน โยน และชนกำแพง
