# วงจรขนลัง Level01 → Level02

## วิธีเล่น

1. Host เปิดห้องใน SampleScene แล้วเปิดประตูไป Level01; เล่นได้ก่อนครบ 4 คน
2. เลือกการ์ด 1 ใบด้วยปุ่ม 1–3 หรือคลิก แล้วหาลังไม้ตามเป้าหมายบนจอ
3. กดเมาส์ซ้าย/ขวาค้างเพื่อจับลัง; Q โยน; ช่วยยกตั้งแต่ 2 คนจะฟื้น Stamina
4. ส่งลังเข้าเขตวงแหวนสีทองที่ปราสาท คะแนน = HP ที่เหลือ × 2 ใน Level01 และ × 3 ใน Level02
5. ทุกคนที่อยู่ในด่านตอนส่งสำเร็จได้รับเหรียญเท่าคะแนน ซื้อไอเทมได้ 3 ช่อง
6. กด Enter หรือ “เดินต่อ” ปิดหน้าสรุป; B เปิดร้านอีกครั้ง; กด 1–3 ใช้ไอเทมเมื่อเมนูปิด
7. ประตู Level01 เปิดหลังส่งสำเร็จ ผู้เล่นคนหนึ่งเดินเข้าแล้วทั้งทีมย้ายไป Level02 ผ่าน NGO SceneManager
8. Level02 ให้ผู้เล่นใกล้คันโยกกด E ค้าง เปิดทางให้เพื่อนขนลัง ประตูเปิด 8 วินาทีหลังหยุดกด และไม่ปิดขณะมีผู้เล่น/ลังอยู่ในช่องทาง
9. ถ้าลัง HP หมด จะแสดงเหตุผล; Host กดเริ่มด่านใหม่ให้ทั้งทีมได้

## การ์ดและร้านค้า

| ชนิด | ผล |
| --- | --- |
| Endurance | ใช้ Stamina ยกคนเดียวน้อยลง 40% |
| Cargo Guard | ขณะผู้ถือการ์ดช่วยจับลัง ลังรับความเสียหายน้อยลง 50%; ไม่ซ้อนตามจำนวนผู้ถือ |
| Teamwork | ผู้ถือการ์ดเดินขณะช่วยยก 2 คนขึ้นไปเร็วขึ้น 15% |
| Stamina Elixir / 40 เหรียญ | ฟื้น Stamina เต็มหนึ่งครั้ง |
| Cargo Padding / 60 เหรียญ | ใช้ขณะจับลัง ลดความเสียหายครั้งถัดไป 50%; ลังมีเกราะได้ครั้งละหนึ่งชุด |

เหรียญและไอเทมติดไปด่านใหม่ การ์ดเลือกใหม่ทุกด่าน การเริ่มด่านเดิมใหม่คืนเหรียญ/ไอเทมตามตอนเริ่มด่าน เพื่อไม่ให้รับรางวัลซ้ำจากการ retry ผู้เข้าหลังส่งสำเร็จไม่ได้รางวัลย้อนหลัง

## โครงสร้าง

- `LevelMission`: อ้างอิงลัง จุดส่ง ประตู และข้อความเป้าหมาย; สถานะล้มเหลวยังคงอยู่หลังลัง despawn
- `ExpeditionHUD`: UI เป้าหมาย การ์ด คะแนน ร้านค้า ช่องไอเทม และคำสั่งคันโยก; เมนูหยุดอินพุตผู้เล่นในเครื่องนั้น
- `PlayerExpeditionState`: Server ตรวจการซื้อ/การใช้/การเลือกการ์ดและถือ NetworkVariable เหรียญ ช่องไอเทม การ์ด
- `DeliveryPoint`: ตรวจจุดส่งใน FixedUpdate, ล็อกลังที่ส่งแล้ว, ซิงก์ผลคะแนนสำหรับผู้เข้าใหม่
- `CarryableObject` / `FragileCargo`: Host จำลองลัง; คิวความเสียหาย คูลดาวน์ โยน และ respawn ใน FixedUpdate; ล้างผู้ยกที่หลุด
- `NetworkPlayer`: Server จองจุดเกิดว่าง; Owner ใช้ PlayerStart ใน FixedUpdate หลังเข้า/เปลี่ยน/เริ่มด่านใหม่
- `TeamLeverGate` / `CoopPressureGate`: Server ตรวจระยะและตำแหน่งผู้เล่นจริง; ซิงก์ประตูทุกเครื่อง
- `GameplayFeedback`: เสียงสั้นและฝุ่นสำหรับยก กระแทก ของแตก ส่งสำเร็จ และประตู

ฉากใช้ทรงเรียบง่ายและวัสดุสีไม้/หิน/หญ้า มีหมู่บ้าน ป่า จุดพัก ปราสาท ธง เกาะและเมฆ เป็นฐานสำหรับตกแต่งต่อ ทางเดิมยังอยู่ ระบบปีนและอนิเมชันไม่ได้ปรับในงานนี้

## Checklist ก่อนส่งเดโม

- เปิด Host และ Client ผ่าน Steam จริง เดินขนลังจนจบเส้นทาง ทั้ง 2 และ 4 คน
- ลองปล่อยมือทีละข้าง โยน ชนฉาก และ Stamina หมด ตรวจว่า HP ไม่ลดจากตัวผู้ยก
- ทดสอบแผ่นกดแบบคนเดียวต้องไม่เปิด และสองคนเปิดได้; ลองคันโยกจาก Client
- เดินเข้าประตูจริง ตรวจชื่อ Level02 และกล้องทุกคน; ลองเข้าใหม่ระหว่างด่าน
- ทำลังแตก แล้วเริ่มใหม่หลายรอบ ตรวจเงินไม่เพิ่มซ้ำและ UI ไม่ซ้อน
- ฟังระดับเสียงและตรวจฝุ่น/แสงประตูบนจอจริง; เปลี่ยนความละเอียด 1280×720 และ 1920×1080
- เก็บเวลาเล่นจริงของแต่ละช่วงเพื่อปรับสมดุลระยะทาง จุดพัก และราคาไอเทม

ยังไม่ได้วัด latency/jitter ของ Steam จริงหรือเล่นเดินตลอดด่านด้วยมนุษย์ การตกแต่งยังเป็นทรงต้นแบบ เสียงจับ ปา เดิน กระแทก และคลิกเปลี่ยนเป็นชุด Sound ที่ผู้ใช้ส่งแล้ว ส่วนเสียงส่งสำเร็จ ประตู และลังแตกยังเป็นเสียงต้นแบบ
